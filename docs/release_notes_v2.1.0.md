## 下载即用（免安装）

1. 下载本页下方的 **`DatasetAnnotationTool_v2.1.0_portable_win64.zip`**（约 248 MB）
2. 解压到任意目录
3. 双击 `数据集标注工具.exe`

**不需要**装 Python、**不需要**装任何依赖、**不需要**联网。整个文件夹拷到任何 Windows 10/11 电脑都能直接运行，卸载 = 删除文件夹（不写注册表）。

> 首次运行若出现「Windows 已保护你的电脑」（SmartScreen），点 **更多信息 → 仍要运行** 即可。这是程序没有购买数字签名证书导致的，不是病毒。

## 功能一览

| 模块 | 说明 |
|---|---|
| 格式转换 | YOLO txt / COCO JSON / Pascal VOC XML 三种格式互转；可选同时复制图片；输出目录与源目录冲突时拒绝执行 |
| 视频抽帧 | 按帧间隔或时间间隔抽帧；可指定 YOLO 模型（.pt/.onnx）自动预标注，阈值可调并记忆 |
| 标注编辑 | 类 LabelImg；滚轮缩放 1×~8×、右键拖拽平移、Ctrl+Z 撤销、删除图片可恢复；框自动限制在图片内 |
| 数据管理 | train/val/test 拆分（可重复运行）、批量重命名（预览 + 冲突预检）、标签校验 |
| 统计分析 | 支持 YOLO / VOC / COCO，导出 HTML 报告 |

## 注意

- **本包不含任何模型权重**：使用「自动标注」时请点「浏览」选择你自己的 `.pt` / `.onnx` 模型；其它功能无需模型。
- 快捷键：`Ctrl+1~5` 切页、`W` 绘制框、`A/D` 上下张、`Delete` 删框、`Ctrl+Z` 撤销、`Ctrl+Del` 删图、`F` 适应窗口。
